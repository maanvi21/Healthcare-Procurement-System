# Archived synthetic risk model

This folder is a preserved copy of the original synthetic risk artifact and its datasets.
The pickle and all copied CSV/JSON files were copied from the existing model, data, and
results folders; the originals remain in place for current references and rollback.

The model was fit against labels generated by the project's `_synthetic_label()` rules.
Its scores measure imitation of those rules, not prediction of confirmed supplier outcomes.
Do not promote it as a real-outcome model or use its synthetic metrics to claim real-world
predictive performance.

Contents:

- `Synthetic_Model.pkl`: original offline scikit-learn artifact.
- `Synthetic_Model_Card.json`: artifact details and provenance.
- `Synthetic_Datasets/`: all/train/validation/test synthetic datasets, copied verbatim.
- `Synthetic_Results/`: original training metrics and validation report.

A new observed-outcome model was not created because no observed supplier-outcome dataset
exists in this workspace. See `../data/README.md` and
`../data/observed_supplier_outcomes_template.csv` for the needed input contract.
